# 💰 FinTrack – Personal Finance Tracker

FinTrack is a modern **web-based personal finance management application** that helps users track their **income, expenses, and budgets** in one secure platform.

It provides a clear overview of financial activity and helps users make smarter financial decisions through insights and automation.

---

## 🚀 Features

### 💸 Expense Tracking
Add, update, and delete expenses securely. Easily understand where your money is being spent every month.

### 💰 Income Management
Track multiple income sources and keep all earnings organized in one place.

### 📊 Monthly Summary
View a clear breakdown of **income vs expenses** with helpful monthly insights.

### 🧠 AI Category Suggestions (AI Categorizer)
FinTrack includes an **AI-powered categorizer** that automatically suggests the most relevant category for an expense based on its **title or description**.  
This helps users save time and maintain consistent expense categorization.

### 🎯 Budget Management
Set monthly budgets for different categories and monitor spending to avoid exceeding limits.

### 🔐 Secure Authentication
JWT-based authentication ensures that user accounts and financial data remain protected.

### 🛡️ Data Privacy
Each user's financial data is **securely isolated** and accessible only by the account owner.
